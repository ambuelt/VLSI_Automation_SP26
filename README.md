# VLSI_Automation_SP26 - ASU Spec2Tapeout ICLAD 2025 Problem

## Problem Set

Your objective is to design tapeout-ready ASICs based on the given problem specifications in the .yaml specification file.

### Setup Instructions:
Install dependencies for Python packages used:

```
pip3 install -r requirements.txt
```

Ensure that you have Codex CLI installed on your WBS Ubuntu environment as described at the following link: https://developers.openai.com/codex/cli

The following commands should make sure that you can run Codex CLI before running the program:

```
npm i -g @openai/codex
codex
```

You can run the docker image as follows to create an environment that has OpenROAD-flow-scripts and iVerilog already installed but the Codex CLI agent should do the following process for you:

```
docker run -it --rm \
  -v ~/iclad_hackathon:/workspace/iclad_hackathon \
  iclad_hackathon:latest bash
```

Inside the docker container, you will find this repository already cloned and available to you in 

```
/workspace/iclad_hackathon/ICLAD-Hackathon-2025/problem-categories
```

### Run the System:

To run the **Finalized** version of the code run from specification to iVerilog evaluation the following command in the WSB Ubuntu terminal:

```
python3 run_codex.py
```

## Workflow Description:

More specifics about the general agent workflow are described in the AGENTS.md file.

Spec -> RTL/Testbench -> iVerilog Synthesis -> OpenROAD (Physical Design) -> Tapeout Ready .odb and .sdc

1. Agent reads *.yaml file for RTL and testbench specification
2. Codex CLI generates RTL and corresponding testbench
3. Run iVerilog simulation
4. Capture log of current run
5. If iVerilog simulation fails
    - Debug and regenerate RTL
    - If iVerilog loops 10 times, exit loop and end agent
6. If successful, write successful_run.txt and move onto OpenROAD *Coming soon*
